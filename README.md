# 빅데이터분석기사 필기 대비 개념 정리

빅데이터분석기사 필기 기출복원 문항을 개념별로 묶고, **2개 이상 회차에서 반복 출제된 개념**만 남겨 정리한 노트입니다.

## 정리 기준

- 출처: [sqldpass 빅데이터분석기사 필기 기출복원](https://www.sqldpass.com/past-exams?cert=BIGDATA_ANALYST) 9개 회차(2·3·4·5·6·7·8·10·13회), 회차당 80문항, 총 720문항
- 개념 제목 옆 숫자는 해당 개념이 출제된 회차 수입니다
- 각 개념 아래 「겹치는 기출」을 펼치면 회차·문항 번호, 문제 요지, 정답 포인트를 볼 수 있습니다 (원문 전재가 아닌 요약)
- 복원 문항이라 원본과 표현이 다를 수 있고, 4회 17번과 8회 14번은 사이트 정답 표기에 혼선이 있어 개념 기준으로 적었습니다
